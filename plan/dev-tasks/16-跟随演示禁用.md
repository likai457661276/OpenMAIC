## 一、功能概述

在教师扩展模式下，通过 Feature Flag 禁用跟随演示功能。跟随演示是指在多人协作场景中，观众端自动跟随演示者的页面动作（翻页、指针移动等）。

### 禁用范围

1. 演示者模式 (Presenter Mode)
2. 跟随者模式 (Follower Mode)
3. 激光笔 (Laser Pointer)
4. 页面动作同步 (Action Sync)
5. 实时光标 (Live Cursor)

## 三、详细实现内容

### 3.1 UI 层禁用

```tsx
<FeatureGate feature="followPresenter">
  <PresenterModeButton />
  <FollowButton />
  <LaserPointer />
</FeatureGate>
```

### 3.2 同步事件过滤

在实时通信层，当 Feature Flag 关闭时，不发送和不处理跟随演示相关事件。

### 3.3 演示模式简化

教师扩展模式下的课件展示使用独立的演示模式（见功能点 06），不依赖原有的跟随演示机制。

## 八、实现记录

### 8.1 实际代码位置

已确认当前项目没有独立的 `components/presenter/`、`lib/follow/` 或专门的跟随同步服务；相关能力主要体现在：
- `components/stage.tsx`：播放页全屏演示状态、F11/方向键/Escape 等演示快捷键。
- `components/canvas/canvas-toolbar.tsx`：全屏演示入口。
- `lib/playback/engine.ts`：`laser` 播放动作。
- `lib/orchestration/tool-schemas.ts`：Agent 可用动作过滤。

### 8.2 已完成改造

- `followPresenter=false` 时，播放工具栏不显示全屏演示入口。
- `followPresenter=false` 时，F11 不再进入应用内演示全屏，`togglePresentation` 入口直接返回。
- `followPresenter=false` 时，播放引擎跳过 `laser` 动作，Agent 提示动作列表中过滤 `laser`。
- 教师扩展模块中已实现的 `SlidePresenter` 是独立课件预览/演示组件，不依赖原有跟随演示同步机制，因此不受本禁用项影响。

### 8.3 实现边界

- 当前代码库未发现多人跟随、实时光标、页面动作同步的独立 WebSocket 通道；因此本次没有新增同步层过滤代码。
- `spotlight` 保留为本地播放视觉强调动作，禁用范围聚焦于计划列出的跟随演示入口与激光笔。
