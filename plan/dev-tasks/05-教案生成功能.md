## 一、功能概述

实现教师模式下的教案创建与 AI 生成能力。教师通过表单输入教学需求（学科、年级、课题、教学目标等），系统调用 OpenMAIC 原有的 AI 生成能力，产出结构化的教案内容。

### 核心目标

1. 提供教案创建表单页面
2. 接入 AI 生成教案内容（通过 Provider 适配层调用）
3. 生成结构化教案（教学目标、重点难点、教学流程、活动设计等）
4. 支持教案的保存、编辑和管理

教案生成需要从中提取或扩展教案相关的数据结构。

## 三、详细实现内容

### 3.1 教案数据模型

**新增文件**：`lib/teacher/types/lesson.ts`

```typescript
export interface LessonPlan {
  id: string;
  title: string;                    // 课题名称
  subject: string;                  // 学科
  grade: string;                    // 年级
  duration: number;                 // 课时（分钟）
  createdAt: Date;
  updatedAt: Date;
  status: 'draft' | 'generated' | 'edited' | 'finalized';

  // 教案核心内容
  objectives: string[];             // 教学目标
  keyPoints: string[];              // 教学重点
  difficulties: string[];           // 教学难点
  teachingProcess: TeachingPhase[]; // 教学流程
  homework: string;                 // 作业设计
  reflection: string;               // 教学反思
}

export interface TeachingPhase {
  name: string;                     // 阶段名称（导入、新授、练习、总结等）
  duration: number;                 // 时长（分钟）
  teacherActivity: string;          // 教师活动
  studentActivity: string;          // 学生活动
  designIntent: string;             // 设计意图
  resources?: string[];             // 教学资源
}

export interface CreateLessonInput {
  subject: string;
  grade: string;
  topic: string;
  objectives?: string[];
  duration?: number;
  style?: string;
  additionalRequirements?: string;
}
```

### 3.2 教案创建页面

**实现文件**：`app/(teacher)/teacher/create-lesson/page.tsx`

页面功能：
- 教案创建表单（学科选择、年级选择、课题输入、教学目标、课时等）
- AI 生成按钮，触发后流式展示生成进度
- 生成完成后跳转到教案详情/编辑页

表单字段：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 学科 | 下拉选择 | 是 | 语文/数学/英语/物理/化学/生物/历史/地理/政治 |
| 年级 | 下拉选择 | 是 | 小学1-6年级/初中1-3年级/高中1-3年级 |
| 课题 | 文本输入 | 是 | 教师输入课题名称 |
| 教学目标 | 多行文本 | 否 | 可选，AI 可自动生成 |
| 课时 | 数字输入 | 否 | 默认45分钟 |
| 教学风格 | 下拉选择 | 否 | 讲授式/探究式/合作式/翻转课堂 |
| 补充要求 | 多行文本 | 否 | 教师补充的特殊要求 |

### 3.3 教案生成服务

**实现文件**：`lib/teacher/lesson-service.ts`

核心功能：
1. 接收教案创建请求
2. 通过 LessonAdapter 调用原有生成能力
3. 解析 AI 生成结果为结构化教案
4. 保存教案数据
5. 返回生成结果

### 3.4 教案详情/编辑页

**实现文件**：`app/(teacher)/teacher/lesson/[id]/page.tsx`

页面功能：
- 展示生成的教案完整内容
- 支持各部分内容的编辑（富文本编辑）
- 教案状态管理（草稿 → 已生成 → 已编辑 → 已定稿）
- 操作按钮：保存、生成课件、生成 Quiz、导出

### 3.5 教案创建表单组件

**新增文件**：`components/teacher/lesson-form.tsx`

表单组件，使用 shadcn UI 组件构建，包含：
- 表单验证
- 学科/年级级联选择
- 生成中的加载状态
- 错误提示

### 3.6 教案展示组件

**新增文件**：`components/teacher/lesson-viewer.tsx`

教案内容结构化展示组件，包含：
- 教学目标展示
- 重点难点标注
- 教学流程时间轴
- 教师/学生活动对比展示
- 设计意图说明

## 六、接口设计

### 创建教案

```
POST /api/teacher/generate-lesson
Body: CreateLessonInput
Response: { lessonId: string; lessonPlan: LessonPlan; }
```

### 获取教案列表

```
GET /api/teacher/lessons
Query: { page?: number; limit?: number; subject?: string; grade?: string; }
Response: { lessons: LessonPlan[]; total: number; }
```

### 获取教案详情

```
GET /api/teacher/lessons/:id
Response: { lesson: LessonPlan; }
```

### 更新教案

```
PUT /api/teacher/lessons/:id
Body: Partial<LessonPlan>
Response: { lesson: LessonPlan; }
```

### 删除教案

```
DELETE /api/teacher/lessons/:id
Response: { success: boolean; }
```

## 八、风险与注意事项

1. **AI 生成质量**：教案生成依赖 Prompt 质量，需要针对不同学科定制 Prompt 模板
2. **生成时间**：AI 生成可能耗时较长，需要实现流式输出或进度提示
3. **数据存储**：需要确认教案数据的持久化方案（数据库 or 文件系统）
4. **并发控制**：多教师同时生成时需要注意 AI 调用的并发限制
5. **国际化**：教案内容目前以中文为主，后续可能需要考虑多语言
