## 一、功能概述

建立教师扩展模块的完整目录结构和路由骨架。该模块将作为独立的功能区域挂载到 OpenMAIC 现有的 Next.js App Router 路由体系中。

### 核心目标

1. 在 `app/` 目录下新增教师扩展模块路由
2. 建立标准化的模块目录结构（pages / components / services / config）
3. 保持与原有路由体系的兼容
4. 提供教师模式的入口与导航

---

## 二、现有代码分析

### 现有路由结构

项目使用 Next.js App Router，现有核心路由如下：

```
app/
  (auth)/           — 认证相关页面（login / signup）
  (main)/           — 主应用区域
    generate/       — 课程生成入口
    course/[id]/    — 课程详情
    history/        — 生成历史
    settings/       — 设置页面
  api/              — API 路由
    generate/       — 课程生成 API
    export/         — 导出 API
    quiz/           — Quiz API
    evaluate/       — 评估 API
  layout.tsx        — 根布局
  page.tsx          — 首页
```

### 现有布局体系

- `app/layout.tsx` — 根布局，包含主题、字体、全局 Provider
- `app/(main)/layout.tsx` — 主应用布局，包含侧边栏、顶部导航
- 使用 `components/ui/` 下的 shadcn 组件库

### 关键依赖文件

| 文件路径 | 说明 |
|---------|------|
| `app/layout.tsx` | 根布局 |
| `app/(main)/layout.tsx` | 主应用布局 |
| `components/ui/` | UI 组件库（shadcn） |
| `components/sidebar/` | 侧边栏组件 |
| `middleware.ts` | 路由中间件（认证等） |

## 三、详细实现内容

### 3.1 新增路由组

在 `app/` 目录下新增教师扩展模块路由组：

```
app/
  (teacher)/                      — 教师扩展路由组
    layout.tsx                    — 教师模式专用布局
    page.tsx                      — 教师工作台首页
    create-lesson/
      page.tsx                    — 创建教案入口
    lesson/[id]/
      page.tsx                    — 教案详情/编辑
      slides/
        page.tsx                  — 课件预览
      quiz/
        page.tsx                  — Quiz 互动
      pbl/
        page.tsx                  — PBL 管理
      export/
        page.tsx                  — 导出页面
    history/
      page.tsx                    — 教案历史列表
    settings/
      page.tsx                    — 教师模式设置
```

### 3.2 教师模式布局

**新增文件**：`app/(teacher)/layout.tsx`

教师模式专用布局，包含：
- 教师模式顶部导航栏
- 教师模式侧边栏（简化版）
- Feature Flag 检查（若 teacherExtension 未启用则重定向）
- 面包屑导航

### 3.3 教师模式专用组件目录

```
components/
  teacher/                        — 教师扩展模块组件
    teacher-nav.tsx               — 教师模式导航栏
    teacher-sidebar.tsx           — 教师模式侧边栏
    lesson-card.tsx               — 教案卡片组件
    lesson-form.tsx               — 教案表单组件
    teacher-breadcrumb.tsx        — 面包屑导航
```

### 3.4 教师模式服务层目录

```
lib/
  teacher/                        — 教师扩展模块服务层
    lesson-service.ts             — 教案服务
    slide-service.ts              — 课件服务
    quiz-service.ts               — 测验服务
    pbl-service.ts                — PBL 服务
    export-service.ts             — 导出服务
```

### 3.5 入口接入

在原有主应用的导航中添加教师模式入口：
- 侧边栏增加「教师工作台」入口链接
- 首页增加教师模式快捷入口
- 使用 `FeatureGate` 组件控制入口的显示/隐藏

## 七、验证方案

1. 所有路由可正常访问，无 404
2. 教师模式布局正确渲染
3. Feature Flag 关闭时，教师模式入口隐藏
4. 中间件正确处理教师路由的认证
5. 侧边栏导航正常跳转

---

## 八、风险与注意事项

1. **路由冲突**：确保 `(teacher)` 路由组不与现有 `(main)` 路由冲突
2. **布局嵌套**：教师模式布局需要正确继承根布局
3. **认证集成**：教师路由需要纳入现有认证体系
4. **占位页面**：初始阶段使用占位页面，后续功能点逐步实现具体内容
5. **与原有导航的融合**：入口需要自然融入现有导航体系，不能显得突兀
