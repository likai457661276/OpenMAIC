## 一、功能概述

在教师扩展模式下，弱化复杂的实时播放控制功能。保留基础的课件翻页和展示控制，但禁用或隐藏时间轴播放、动画时序控制、自动播放等复杂功能。

### 保留能力

1. 基础翻页（上一页/下一页）
2. 页面跳转
3. 全屏展示

### 弱化/禁用能力

1. 时间轴播放控制
2. 动画时序精确控制
3. 自动播放定时器
4. 复杂过渡效果控制面板
5. 播放速度控制

## 三、详细实现内容

### 3.1 播放控制简化

当 `complexRealtimePlayback` Feature Flag 关闭时：
- 隐藏时间轴控制面板
- 隐藏自动播放选项
- 隐藏播放速度控制
- 隐藏动画时序编辑器
- 保留基础翻页和全屏控制

### 3.2 教师模式播放器

教师模式使用简化版播放器（在功能点 06 中实现的 SlidePresenter），不加载复杂播放控制组件。

## 八、实现记录

### 8.1 实际代码位置

经代码检查，当前项目未发现独立 `components/player/` 或 `components/timeline/` 目录。复杂播放控制主要分布在：

| 文件路径 | 实际职责 |
|---------|----------|
| `components/canvas/canvas-toolbar.tsx` | 播放工具条、速度、自动播放、全屏、翻页 |
| `components/roundtable/index.tsx` | 播放模式底部交互区、气泡播放/暂停、自动播放与速度状态 |
| `components/stage.tsx` | 播放引擎创建、键盘快捷键、自动播放推进、播放速度同步 |
| `lib/playback/engine.ts` | 播放引擎动作调度与无音频阅读计时 |
| `components/teacher/slide-presenter.tsx` | 教师课件简化演示器 |

### 8.2 完成改造

在教师模式上下文中，当 `complexRealtimePlayback=false` 时：

- `CanvasToolbar` 隐藏讲解播放/暂停、播放速度控制、自动播放控制。
- `Roundtable` 不再通过普通讲解气泡触发播放/暂停，也不展示讲解播放状态图标。
- `Stage` 禁用空格键触发讲解播放/暂停。
- `Stage` 强制关闭残留的 `autoPlayLecture`，并把残留播放速度恢复为 `1x`。
- `Stage` 自动播放完成回调只在 `complexRealtimePlayback=true` 时推进下一页。
- `PlaybackEngine` 的无音频阅读计时在该开关关闭时固定按 `1x` 计算。
- 普通 `/classroom/...` 课堂不套用教师扩展禁用开关，继续保留原有播放/暂停、倍速、自动播放、全屏和音频播放能力。

### 8.3 保留能力

- 保留上一页/下一页和页码展示。
- 保留侧栏、对话区收起控制。
- 全屏入口仍由 `followPresenter` 独立控制；`complexRealtimePlayback` 不额外禁用全屏。
- 教师课件页 `SlidePresenter` 继续作为简化演示器使用，只提供翻页、退出和备注展示。

### 8.4 验证点

- 默认教师扩展配置下，复杂播放控制为关闭状态。
- 教师模式开关关闭时工具条不出现速度与自动播放按钮。
- 教师模式开关关闭时本地旧设置中的自动播放/倍速不会继续影响播放运行层。
- 普通 `/classroom/...` 渲染页仍能显示并触发原播放控件。
- 开关开启时原有复杂播放控制可恢复。
