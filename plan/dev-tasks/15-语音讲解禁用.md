## 一、功能概述

在教师扩展模式下，通过 Feature Flag 禁用语音讲解（TTS/语音生成）和语音播放功能。降低系统对语音模型和音频生成的依赖，减少部署复杂度。

### 核心原则

1. **不删除代码**：保留语音相关的所有代码文件
2. **UI 层隐藏**：隐藏语音播放按钮、语音控制面板
3. **生成层跳过**：课件生成时跳过语音生成步骤
4. **API 层保护**：语音相关 API 在 Feature Flag 关闭时返回 403
5. **可恢复**：Feature Flag 打开后，语音功能完全恢复

```tsx

</FeatureGate>
```

- 课件播放页的语音播放按钮

在课件生成流程中，当 `voiceNarration` Feature Flag 关闭时，跳过语音生成步骤：

```typescript
if (getFeatureFlag('voiceNarration')) {
  await generateNarration(slide);
}
```

### 3.4 API 层保护

语音相关 API 添加 Feature Flag 检查。

1. Feature Flag 关闭时无语音相关 UI
2. 课件生成不包含语音生成步骤（生成速度应明显加快）
3. 语音 API 返回 403

## 七、风险与注意事项

1. **生成流程耦合**：语音生成可能与课件生成深度耦合，需要仔细处理跳过逻辑
2. **数据模型影响**：Slide 数据模型中可能包含语音字段，禁用后这些字段为空即可
3. **前端播放依赖**：播放控制可能与 Slide 翻页逻辑耦合
4. **音频资源**：禁用后不需要清理已有音频资源

## 八、实现记录

### 8.1 实际代码位置

已确认当前语音能力主要分布在：
- `lib/hooks/use-scene-generator.ts`：课件生成后的 TTS 生成与存储。
- `app/api/generate/tts/route.ts`：服务端 TTS 生成 API。
- `app/api/azure-voices/route.ts`：Azure TTS 语音列表 API。
- `components/canvas/canvas-toolbar.tsx`：播放页音量/静音控制入口。
- `lib/playback/engine.ts`：播放引擎中的预生成音频和浏览器原生 TTS 播放。
- `lib/teacher/teacher-mode-provider.tsx`、`components/generation/media-popover.tsx`、`components/settings/index.tsx`：既有教师模式语音开关联动与 UI 隐藏。

### 8.2 已完成改造

- `voiceNarration=false` 时，课件生成流程跳过服务端 TTS 生成，不再调用 `/api/generate/tts`。
- 教师模式请求中 `voiceNarration=false` 时，`/api/generate/tts` 与 `/api/azure-voices` 返回 403；普通课堂生成与原有 TTS API 行为保持可用。
- `voicePlayback=false` 时，播放工具栏隐藏音量/静音控制。
- `voicePlayback=false` 时，播放引擎不播放预生成音频，也不触发浏览器原生 TTS，改为按阅读时长推进。
- 教师模式 Provider 保留既有行为：语音讲解关闭时禁用 TTS，语音播放关闭时禁用 ASR。

### 8.3 实现边界

- 已有音频资源不会被删除；禁用后仅跳过生成与播放。
- Slide/Action 数据模型中已有 `audioId` 字段保持兼容，禁用播放时不会消费该字段。
- Canvas/Stage/PlaybackEngine 中的语音播放禁用只在教师模式上下文中生效；普通 `/classroom/...` 课堂保持原有播放能力。
