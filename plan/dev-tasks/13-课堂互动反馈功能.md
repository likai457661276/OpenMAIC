## 一、功能概述

实现课堂互动反馈功能，教师可以在课堂中实时收集学生反馈，了解学生掌握情况，根据反馈调整教学节奏。

### 核心目标

1. 提供多种反馈收集方式（快速投票、理解度评估、自由反馈）
2. 教师端实时查看反馈汇总
3. 基于反馈数据辅助教学决策
4. 生成课堂反馈报告

## 三、详细实现内容

### 3.1 反馈数据模型

**新增文件**：`lib/teacher/types/feedback.ts`

```typescript
export type FeedbackType =
  | 'quick-poll'         // 快速投票（是/否/不确定）
  | 'understanding'      // 理解度（5级评估）
  | 'emoji-reaction'     // 表情反馈
  | 'free-text'          // 自由文字反馈
  | 'rating';            // 评分反馈

export interface FeedbackSession {
  id: string;
  lessonId: string;
  type: FeedbackType;
  question: string;              // 反馈问题
  responses: FeedbackResponse[];
  createdAt: Date;
  closedAt?: Date;
  status: 'active' | 'closed';
}

export interface FeedbackResponse {
  participantId: string;
  participantName: string;
  value: string | number;
  submittedAt: Date;
}

export interface FeedbackSummary {
  sessionId: string;
  totalResponses: number;
  distribution: Record<string, number>;  // 各选项的响应数
  averageRating?: number;                // 平均评分（rating 类型）
  textResponses?: string[];              // 文字反馈列表
}

export interface ClassroomFeedbackReport {
  lessonId: string;
  feedbackSessions: FeedbackSession[];
  overallUnderstanding: number;          // 整体理解度
  participationRate: number;             // 参与率
  keyInsights: string[];                 // 关键发现
}
```

## 七、风险与注意事项

1. **实时性能**：大量学生同时提交反馈的并发处理
2. **可视化库选择**：需要选择合适的图表库（推荐 recharts 或 chart.js）
3. **隐私保护**：自由文字反馈可能涉及学生隐私，教师端展示需注意
4. **与答题会话复用**：反馈功能需要复用答题会话的实时通信通道
