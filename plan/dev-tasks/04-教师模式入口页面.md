## 一、功能概述

基于 OpenMAIC 原有首页（`app/page.tsx`）进行裁剪和定制，创建教师模式专用的入口页面。**不是另建一套独立工作台**，而是复用原有首页的核心交互模式（需求输入 → AI 生成 → 进入课堂），通过 Feature Flag 隐藏教师模式不需要的功能配置项。

### 核心目标

1. 保留原首页的核心交互：需求输入框 → 生成课堂内容
2. 通过 Feature Flag 隐藏/禁用不需要的功能配置（TTS、ASR、语音播放等）
3. 保留需要的功能配置（AI Provider 选择、PDF 上传、Web Search、图片生成、视频生成）
4. 保持与原首页一致的视觉风格和交互体验
5. 最近课堂列表等功能完整保留

## 三、详细实现内容

### 3.1 实现策略：Feature Flag 条件渲染（推荐）

**不复制原首页代码**，而是在原有组件中注入 Feature Flag 判断。这样可以：
- 减少代码重复
- 原首页功能更新时自动获益
- 教师模式仅通过 Flag 控制差异

#### 入口页面

**实现文件**：`app/(teacher)/page.tsx`

教师模式入口页面，核心策略是**复用原有 `HomePage` 组件**，通过 props 或 Context 传入 Feature Flag 配置：

```typescript
// 方案 A：包装原首页，注入教师模式上下文
export default function TeacherHomePage() {
  return (
    <TeacherModeProvider>
      <HomePage />
    </TeacherModeProvider>
  );
}

// 方案 B（备选）：如果原首页不方便改造，
// 则 fork 一份精简版首页，复用原有子组件
```

### 3.2 MediaPopover 裁剪

**修改文件**：`components/generation/media-popover.tsx`

通过 Feature Flag 控制 Tab 显示：

```typescript
const TABS_FILTERED = TABS.filter(tab => {
  if (tab.id === 'tts' && !getFeatureFlag('voiceNarration')) return false;
  if (tab.id === 'asr' && !getFeatureFlag('voicePlayback')) return false;
  return true;
});
```

- `voiceNarration = false` → 隐藏 TTS Tab
- `voicePlayback = false` → 隐藏 ASR Tab
- Image 和 Video Tab 始终保留

### 3.3 SettingsDialog 裁剪

**修改文件**：`components/settings/` 相关文件

通过 Feature Flag 控制设置面板中的配置节：

```typescript
// SettingsSection 类型定义中有：'tts' | 'asr' | ...
// 教师模式下隐藏 'tts' 和 'asr' 配置节

const visibleSections = ALL_SECTIONS.filter(section => {
  if (section === 'tts' && !getFeatureFlag('voiceNarration')) return false;
  if (section === 'asr' && !getFeatureFlag('voicePlayback')) return false;
  return true;
});
```

### 3.4 生成参数固化

**修改文件**：`app/page.tsx` 中的 `handleGenerate` 函数

教师模式下固化部分生成参数：

```typescript
const requirements: UserRequirements = {
  requirement: form.requirement,
  userNickname: userProfile.nickname || undefined,
  userBio: userProfile.bio || undefined,
  webSearch: form.webSearch || undefined,
  // 教师模式固定关闭互动模式
  interactiveMode: getFeatureFlag('complexRealtimePlayback') ? interactiveMode : false,
};
```

### 3.5 Settings Store 初始值覆盖

教师模式下，通过 Feature Flag 覆盖 Settings Store 中的相关开关初始值：

```typescript
// 教师模式启动时自动设置
if (getFeatureFlag('teacherExtension')) {
  if (!getFeatureFlag('voiceNarration')) {
    useSettingsStore.getState().setTTSEnabled(false);
  }
  if (!getFeatureFlag('voicePlayback')) {
    useSettingsStore.getState().setASREnabled(false);
  }
}
```

## 八、风险与注意事项

1. **原首页耦合度**：如果原首页代码高度耦合，无法通过 props/context 注入 Flag，可能需要 fork 一份。但应尽量避免 fork，优先使用条件渲染方案
2. **MediaPopover 改动影响**：修改 MediaPopover 会影响原首页。需要确保非教师模式下（Feature Flag 全开）行为不变
3. **Settings Store 状态冲突**：教师模式覆盖的 Store 状态需要在退出教师模式时恢复，或者使用独立的 Store 命名空间
4. **路由区分**：教师模式入口页在 `(teacher)` 路由组下，需要确保导航逻辑正确区分原首页和教师首页
5. **SSR 兼容**：Feature Flag 读取需要兼容服务端渲染，避免 hydration mismatch
