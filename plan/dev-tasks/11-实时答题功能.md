## 一、功能概述

接入 OpenMAIC 原有的实时答题能力，使教师可以在课堂中发起实时答题活动。学生通过设备（手机、平板、电脑）参与答题，教师端实时查看答题进度和结果。

### 核心目标

1. 教师端发起实时答题会话
2. 生成答题入口（二维码/链接/会话码）
3. 学生端实时答题界面
4. 教师端实时查看答题进度
5. 答题结束后展示结果统计

## 三、详细实现内容

### 3.1 实时答题数据模型

**新增文件**：`lib/teacher/types/realtime-quiz.ts`

```typescript
export interface QuizSession {
  id: string;
  quizSetId: string;
  sessionCode: string;           // 会话码（6位数字）
  teacherId: string;
  status: 'waiting' | 'active' | 'paused' | 'completed';
  currentQuestionIndex: number;
  participants: Participant[];
  startedAt?: Date;
  endedAt?: Date;
  settings: SessionSettings;
}

export interface Participant {
  id: string;
  name: string;
  joinedAt: Date;
  answers: ParticipantAnswer[];
  totalScore: number;
}

export interface ParticipantAnswer {
  questionId: string;
  answer: string | string[];
  isCorrect: boolean;
  score: number;
  answeredAt: Date;
  timeTaken: number;             // 答题耗时（秒）
}

export interface SessionSettings {
  showResultsImmediately: boolean;  // 答题后立即显示结果
  allowLateJoin: boolean;           // 允许中途加入
  questionTimeLimit?: number;       // 每题时限（秒）
  shuffleQuestions: boolean;        // 题目乱序
  shuffleOptions: boolean;          // 选项乱序
}
```

## 六、接口设计

### 创建答题会话

```
POST /api/teacher/quiz-session
Body: { quizSetId: string; settings: SessionSettings; }
Response: { session: QuizSession; }
```

### 学生加入

```
POST /api/teacher/quiz-session/:id/join
Body: { name: string; }
Response: { participantId: string; }
```

### 提交答案

```
POST /api/teacher/quiz-session/:id/answer
Body: { participantId: string; questionId: string; answer: string | string[]; }
Response: { isCorrect: boolean; score: number; }
```

### WebSocket 事件

```
// 教师端 → 服务器
'start-session'
'next-question'
'pause-session'
'end-session'

// 服务器 → 学生端
'question-start'
'question-end'
'session-end'
'results'

// 学生端 → 服务器
'submit-answer'

// 服务器 → 教师端
'participant-joined'
'answer-received'
'all-answered'
```

## 八、风险与注意事项

1. **实时通信架构**：需要确认原有项目的实时通信方案，选择兼容的技术
2. **并发处理**：大量学生同时答题的并发压力
3. **网络稳定性**：需要处理断线重连、答案缓存等场景
4. **安全防作弊**：需要基本的防作弊措施
5. **部署要求**：WebSocket 可能需要额外的服务器配置
