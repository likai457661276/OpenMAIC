## 一、功能概述

保留并接入 OpenMAIC 原有的在线评分能力。系统根据学生提交的答案，自动进行评分（客观题自动批改，主观题 AI 辅助评分），并生成评分报告。

### 核心目标

1. 客观题（选择、判断、填空）自动评分
2. 主观题（简答）AI 辅助评分
3. 评分结果实时反馈给教师和学生
4. 生成评分统计报告

## 三、详细实现内容

### 3.1 评分数据模型

**新增文件**：`lib/teacher/types/scoring.ts`

```typescript
export interface ScoringResult {
  sessionId: string;
  participantId: string;
  totalScore: number;
  maxScore: number;
  percentage: number;
  questionResults: QuestionResult[];
  gradedAt: Date;
}

export interface QuestionResult {
  questionId: string;
  score: number;
  maxScore: number;
  isCorrect: boolean;
  submittedAnswer: string | string[];
  correctAnswer: string | string[];
  feedback?: string;            // AI 评语
  gradingType: 'auto' | 'ai-assisted' | 'manual';
}

export interface SessionReport {
  sessionId: string;
  quizTitle: string;
  participantCount: number;
  averageScore: number;
  highestScore: number;
  lowestScore: number;
  scoreDistribution: ScoreRange[];
  questionAnalysis: QuestionAnalysis[];
}

export interface QuestionAnalysis {
  questionId: string;
  content: string;
  correctRate: number;
  averageTime: number;
  commonWrongAnswers: string[];
}
```

## 六、验证方案

1. 客观题自动评分准确率 100%
2. 主观题 AI 评分结果合理
3. 评分报告数据统计正确
4. 成绩分布图正确展示
5. 学生可查看自己的评分详情

---

## 七、风险与注意事项

1. **AI 评分准确性**：主观题 AI 评分需要教师确认，不能完全依赖 AI
2. **评分公平性**：需要保证评分标准一致
3. **性能**：大量学生答案的批量评分需要注意性能

## 八、实现记录

当前版本已实现在线评分基础能力：

- 新增 `lib/teacher/types/scoring.ts` 与 `lib/teacher/scoring-service.ts`。
- 客观题按标准答案自动评分，简答题以 AI 辅助评分占位策略处理，并明确需要教师复核。
- 新增 `app/api/teacher/scoring` 与 `app/api/teacher/scoring/report`。
- 教师端答题会话页已展示评分统计和报告。
- 新增 `score-report.tsx`、`score-distribution.tsx`、`question-analysis.tsx`、`student-score-card.tsx`。

### 当前边界

- 主观题尚未调用真实 Provider 评分，当前为可运行的辅助评分占位。
- 评分结果由答题会话中的提交记录即时计算，尚未单独落地评分历史文件。
